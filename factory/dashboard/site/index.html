Each box is a "station" of the LibreLane Classic flow (80 steps grouped into 22). Green = every step in the station wrote its state_out.json and the run exited 0; red = a step failed or a deferred checker (timing, DRC, LVS, XOR) blamed this station; grey = not reached. The design flows left to right: text (RTL) becomes gates, gates get positions, positions get wires, wires get checked, and the result is a GDS file the foundry can print.

Timing (signoff STA, per corner)

Setup slack is how much earlier than required the data arrived at the slow/hot/low-voltage corner (ss_100C_1v60, max RC); negative means the chip cannot run at CLOCK_PERIOD. Hold slack is how long the data stayed stable after the clock edge at the fast/cold/high-voltage corner (ff_n40C_1v95, min RC); negative means the chip is broken at any frequency. The flow subtracts 0.25 ns clock uncertainty and applies ±5 % derate before reporting these numbers. TNS adds up all negative slacks; "vio" counts violating endpoints.

Area / utilization / power

Instance area is the sum of standard-cell areas (um²); utilization is that area divided by the core area; a sky130 1x1 Tiny Tapeout tile is 161.00 x 111.52 um and fits roughly 1000 gates. Power is OpenSTA's vectorless estimate (internal + switching + leakage) at the nominal corner.

Decisions timeline (closure loop)

    When a run fails a checker, the orchestrator applies one rule from a fixed table (synthesis strategy → utilization → clock period for setup; density → routing adjustment for congestion; resizer margins → CTS clustering for hold; repair iterations → diodes for antennas) and re-runs. Every change is recorded with the metrics before and after, so a human can audit why the final configuration looks the way it does.

    Sweep: WIDTH × CLOCK_PERIOD

    The same MAC was hardened at operand widths 2, 4 and 8 bits and several clock periods. Area should grow roughly with the square of the width (the multiplier), worst slack should get worse as the clock period shrinks, and the point where WNS crosses zero is the fastest clock the design closes at.
